# 🤖 Product Review Classification using Machine Learning

A machine learning project that analyzes customer reviews and classifies them into **Positive, Negative, or Neutral** sentiment categories.

## 🎯 Project Objective

The goal of this project is to automatically understand customer sentiment from product reviews using Natural Language Processing and Machine Learning techniques.

## ✨ Features

- 📝 Customer Review Analysis
- 😊 Positive Sentiment Detection
- 😐 Neutral Sentiment Detection
- 😞 Negative Sentiment Detection
- 🔤 Text Vectorization using TF-IDF
- 🤖 Machine Learning Classification
- 📊 Sentiment Visualization
- ⌨️ Custom Review Prediction

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF Vectorizer
- Support Vector Machine (SVM)
- Matplotlib
- Jupyter Notebook

## ⚙️ How It Works

```text
Customer Review
      ↓
Text Preprocessing
      ↓
TF-IDF Vectorization
      ↓
SVM Model
      ↓
Sentiment Prediction
      ↓
Positive / Negative / Neutral
```

## 📊 Dataset

The dataset contains information such as:

- Product ID
- Product Name
- Customer Name
- Customer Review
- Positive
- Negative
- Neutral
